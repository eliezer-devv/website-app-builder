ANDROID · WEBSITE WRAPPER

Turn a website
into an app.

Enter the website, choose the app name and icon, then build an installable APK using GitHub Actions.

1. App details

HTTPS is required. Entering example.com is fine; https:// will be added automatically. Top-level navigation is restricted to the configured hostname.

Suggested from the domain. Use lowercase letters and numbers separated by dots, with at least two parts. Keep the same package name to update the same app.

Upload a square icon
PNG, JPG or WebP, maximum 10 MB. Center-cropped to a square.

If you skip this, the template's current icon is used. A previously uploaded icon remains unless replaced.

2. Connect to GitHub

This builder uses one fixed repository, so no username or repository name is needed.

Repository: eliezer-devv/website-app-builder
App settings and uploaded icons are committed to this public repository, so the website URL, app name, package name and icon will be publicly visible. Do not enter private URLs or sensitive information.
Token requirements: restrict the token to eliezer-devv/website-app-builder and grant Contents: Read and write and Actions: Read and write. The token is used in this browser tab to call GitHub directly. It is not saved in browser storage or sent to a separate server. Close or refresh the page when finished.
Ready when you are. The repository must contain this template and its Build APK workflow.

After downloading, extract the ZIP and install the APK inside. Setup instructions.
