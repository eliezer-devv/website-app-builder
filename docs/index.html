Website APK Builder

Enter a website and create an Android APK that opens it.

Use a fine-grained token limited to the website-app-builder repository. The token is cleared after the build attempt.

Use a unique package name, such as com.yourname.mywebsite.

Choose a square image if possible. PNG is recommended.

Enter one hostname per line. You can also paste a comma-separated list. Blank lines and lines beginning with # are ignored. Enter hostnames only — no https://, paths, ports, or wildcards. The original website and its subdomains are allowed automatically.
