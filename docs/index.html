Website APK Builder

Enter a website and create an Android APK that opens it.

Use a fine-grained token limited to the website-app-builder repository, with the permissions required by this builder. Remembering your token stores it in this browser's local storage. Do not enable this on a shared or untrusted device.

Use a unique package name, such as com.yourname.mywebsite.

Enter one hostname per line. You can also paste a comma-separated list. Blank lines and lines beginning with # are ignored. Enter hostnames only — no https://, paths, ports, or wildcards. The original website and its subdomains are allowed automatically.

When enabled, the generated APK allows the additional Google domains needed for Google account sign-in. Leave unchecked if not needed.
