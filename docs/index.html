Website to APK Builder

Turn a website into an Android app. Choose the website, set the app name and package name, and optionally provide an app icon.

Build APK

How it works

  1. Enter your app details in the form.
  2. Submit the form to start the build.
  3. Open the build in GitHub Actions when it finishes.
  4. Download the website-app-apk artifact.

Builds run through GitHub Actions. The APK artifact is available for 14 days after the build finishes.
